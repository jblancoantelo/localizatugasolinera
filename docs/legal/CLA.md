## 12. Cómo firmar

### 12.1 Firma electrónica simple mediante pull request (recomendada)

1. Abre un pull request que añada tu entrada al fichero
   [`CLA-firmas.json`](./CLA-firmas.json):

   ```json
   {
     "github": "tu-usuario-de-github",
     "nombre": "Nombre Apellidos",
     "email": "tu@correo.example",
     "tipo": "individual",
     "fecha": "2026-10-29",
     "cla": "1.0"
   }
   ```

2. En el cuerpo del pull request escribe: *"Acepto el CLA v1.0 del Proyecto."*

El commit queda registrado en el historial de Git con tu usuario, tu correo y la
fecha, lo que sirve como evidencia de la aceptación. El bot
`.github/workflows/cla.yml` avisa automáticamente si un PR llega sin firma.

### 12.2 Firma manuscrita o electrónica cualificada

Si prefieres una firma formal, imprime el Anexo A (o el Anexo B), fírmalo y
envía el PDF escaneado o firmado electrónicamente (eIDAS) al correo de contacto
del Proyecto. La firma electrónica cualificada tiene la misma validez que la
manuscrita.

### 12.3 Contribuciones en nombre de una empresa

Si contribuyes como empleado o en nombre de una entidad, debe firmar el
**Anexo B**. La firma cubre a los usuarios de GitHub que la entidad indique.

### 12.4 Menores de edad

Si eres menor de edad, la firma debe realizarla tu representante legal.
