🤖 Claves API - IA

Las claves se guardan en localStorage. Si es la primera vez, introduce la contraseña para cargar las claves por defecto.

LLM7.io funciona sin clave (acceso anónimo, 500k tokens/día). Con un token gratuito de dash.llm7.io el límite sube a 1M tokens/día. Los catálogos de modelos se actualizan solos: si un modelo desaparece, el chat te avisa y te ofrece la lista nueva sin necesidad de tocar código.

NVIDIA (vía proxy): NVIDIA solo habilita el origen build.nvidia.com, así que desde la app el navegador rechaza su API. Por eso se usa el Worker de workers/: la clave nvapi-… vive allí como secreto y el navegador solo necesita su URL.

La URL que viene puesta es un ejemplo, no funciona: Cloudflare publica cada Worker como https://petrol-nvidia-proxy.<tu-cuenta>.workers.dev (el subdominio de la cuenta es lo único que no puedes elegir) y el valor por defecto se queda sin él, así que ese host no existe. Mientras no pegues la real, NVIDIA aparece como no disponible en el chat y no se hace ninguna petición; el resto de proveedores no necesitan nada de esto.

Para desplegarlo (hace falta una cuenta de Cloudflare, gratuita): cd workers → wrangler secret put NVIDIA_API_KEY → wrangler deploy. El comando imprime la URL con el subdominio: cópiala al campo de arriba y pulsa 🔎 Probar, que te dice si el Worker existe, si le falta la clave o si NVIDIA la rechaza. La clave nunca se guarda en el navegador y, al cambiar la URL, el catálogo de modelos se vuelve a consultar.

🧩 Pestañas de IA

Elige qué proveedores aparecen en la pestaña IA. Por defecto están todos; desmarca los que no uses y dejan de mostrarse (su chat y sus mensajes se conservan por si los vuelves a activar).
